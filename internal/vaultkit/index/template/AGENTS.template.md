## Invariants that hold no matter how you connect

- **Nothing you do here reaches the network.** Classification and OCR run
  on-device; the only network call anywhere in Kagaz is an explicit, human-
  run `kagaz model pull`.
- **Every mutation previews before it commits** and needs explicit approval
  (`--yes`/`--accept-proposal` on the CLI). Approval is always a CLI call:
  no MCP tool mutates, so no MCP argument can execute one either.
  `--propose-only` always exits without mutating.
- **A document tagged `confidential` cannot be resolved for external send
  without explicit confirmation**, and an audit line is written either way
  — there is no flag or JSON mode that skips either. See
  [docs/commands.md#resolve---for-send](https://getkagaz.github.io/kagaz/commands.html#resolve---for-send).
- **No MCP tool executes a mutation on its own.** `ingest_propose` returns a
  proposal; a human (or the CLI, driven by a human's explicit approval)
  executes it. This friction is deliberate, not a missing feature.
- **A vault document is never deleted.** A "move" relocates the file into
  its conventional place and retires the source into a staging folder only
  the vault's owner empties.
- **Every mutation is reversible** via `kagaz rollback <manifest>`.
